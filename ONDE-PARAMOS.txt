Atualizado em 31/10/2026

1. ESTADO ATUAL: PRONTO E FUNCIONANDO
========================================================================

O agente lê histórias de usuário em Markdown (stories/), gera cenários
Gherkin em português (features/generated/), preenche o formulário do
DemoQA pela interface e valida campo a campo, inclusive a tela de
confirmação.

Última execução completa:
  - 7/7 cenários passando no navegador (US-001, US-002 e US-003)
  - 23/23 testes unitários passando

  - JSON de importação do Xray em reports/xray-execution.json

========================================================================
2. COMO RODAR
========================================================================

  npm install
  npx playwright install chromium
  npm run qa              compila histórias + roda e2e + gera export Xray

Outros comandos:
  npm run stories:compile   gera/atualiza os .feature
  npm run stories:check     só confere se os .feature estão atualizados
  npm run test:e2e          roda os cenários no navegador
  npm run test:unit         testes unitários
  npm run typecheck         checagem de tipos
  npm run xray:export       gera o JSON do Xray (--upload para enviar)

4. REGRAS DE CONFIDENCIALIDADE (VALEM PARA REPO E POST)
========================================================================

Tudo neste repositório é fictício e roda contra o DemoQA (site público
de prática). Nunca incluir: nome do cliente ou da empresa, plataforma
usada no trabalho, prints de telas reais, nomes de formulários ou
campos reais, dados de qualquer tipo, código interno, nomes de colegas
ou métricas que identifiquem a operação.

========================================================================
5. SOBRE A IA (CHAVE DA API)
========================================================================

A chave ANTHROPIC_API_KEY é opcional. Sem ela, histórias em texto livre
que ainda não têm .feature são puladas com aviso, e o resto funciona.
As que já têm .feature versionado (como a US-003) são reaproveitadas.
Para histórias novas em texto livre, há duas opções:
  - pedir ao Claude Code para gerar o .feature (sem custo extra), ou
  - colocar a chave num arquivo .env (copie de .env.example) e rodar
    npm run stories:compile. A API é cobrada à parte da assinatura.
